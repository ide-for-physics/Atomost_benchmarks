## 三臂

1. **harness + Haiku 5.5**：材料建在独立的基准材料库 `benchmarks/cophon_bench/e2e_library/`（复制了共享的案例库与事件日志），
   `cophon --library … supervise` 作为 systemd 用户单元 `cophon-bench-e2e` 无人值守；出工单时由 `benchmarks/cophon_bench/ticket_relay.py`
   让 Haiku 在全新上下文里答题，流水线校验器验过后由本会话原样应用（Fable 与 DeepSeek 作影子，只记录不应用）；升级到 owner 的由本会话裁决。
   人工触碰次数（应用、裁决）全部计数。结果不导出到 Explorer（`--no-export-cards`，且不在真材料库里）。
2. **harness + Fable 5.1**：只在 Haiku 的答案与 Fable 影子不同且会改变走向时另起一份（避免重复算力）；工单为零的材料两臂等价，这本身是结论。
3. **白板 Fable 5.1**：无头会话（`claude -p --model fable`）在仓库之外的独立目录 `<whiteboard>/<M>_whiteboard/` 启动，
   只拿到：结构（CIF/POSCAR）、论文正文与 SI、作者实现笔记、LUMI 工具链路径（QE 7.5 + 核变体 EPW，含源码）、赝势路径、独立远程根目录、分区与机器怪癖、20 节点时上限、3 天墙钟。
   任务书 `TASK.md`（同目录）。允许的工具：ssh/rsync/scp、python、常用文件命令、读写文件；无网络。

## 隔离的真实边界（诚实声明）

- 无头会话在本会话的权限设置下**不能**做文件系统沙箱（bwrap 绑定与凭据复制都被权限分类器拒绝），也**不能**去掉用户级全局指令文件（`~/.claude/CLAUDE.md` 总会载入，
  其中提到 HPC 手册的路径）。隔离因此靠三道线：任务书里的禁止清单；独立的本地目录与远程根目录；**完整的工具调用记录**（`transcript.jsonl`，stream-json）事后审计——
  凡读取或执行了 `~/9.coherent_phonon`（或其它项目目录）下任何文件，该臂记为"污染"，结果作废并如实报告。
- 两臂共用的东西（不算 harness）：工具链、赝势、集群、论文。harness 独有的：流程代码、规则、策略、案例库、工单合同、监督器、health、成本表。

## 判分（代码判，事后）

| 指标 | 怎么量 |
|---|---|
| 完成 | 产出核文件 + 报告；或在上限内停 |
| 峰位 / 峰高 / 最强模式 对基线 | 峰位 ±0.15 eV、峰高 ±25%、模式同一支（频率 ±5%）为"同一答案" |
| Wannier 质量 | 白板臂留下的带比较数据用流水线的分数门复判（score ≤ 0.9、spread ≤ 10 Å²）；没留数据按"不可验证"记 |
| 算力 | `sacct` 按作业号汇总节点时（白板臂的 jobs.log 为辅）；harness 臂用 `cophon cost` |
| 墙钟 | 启动到 DONE |
| 人工触碰 | harness 臂：应用的答案数 + owner 裁决数；白板臂：0（无人可问） |
| 模型花费 | 运行器/会话记录（list 价） |

## 上限与风险

- 算力上限：harness 臂 3 × ≤ 5 节点时；白板臂 3 × 20 节点时；合计 ≤ 75 节点时（约 $375 按 $5/节点时）。
- 白板臂先只飞 GaP（最易）；看其行为与消耗后再决定 SnS2、NbFeSb 是否放行（owner 授权范围内由本会话决定）。
- 白板臂可能占用 debug 分区、与三条飞行争队列：任务书限制其 debug 用法（<10 分钟、一次一个）。
- 白板臂会话的模型预算上限 $120、600 轮；超限即停并算"未完成"。
