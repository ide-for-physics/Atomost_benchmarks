# atomost-bench v0 (2026-10-17)

The first benchmark of **atomost**, the layer through which every Claude agent session of our four-person team starts: one
memory home per project curated by a resident strategist session, records, per-project cost accounting, and a phone console that
flags sessions needing a human. It measures that layer, not a research pipeline.

- English summary: [report/SUMMARY.en.md](report/SUMMARY.en.md)
- Full report (Chinese, public edition): [report/REPORT.md](report/REPORT.md)
- Grading tables: [tables/](tables/) (per-answer letters and keys in `t1_detail.json`; no item text)
- Design, freeze note and checksum list, runner and figure scripts: [design/](design/)

Held privately, available for diligence on request: the item texts and quotes (the team's internal rules), the frozen memory copies,
per-run answers and full transcripts, the replay data and the atomost code.
