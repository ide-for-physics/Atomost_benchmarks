# Public experimental data for the next monolayer-TMDC calculation

Völzer *et al.* (2025) publish raw, processed, fitted, Fourier-amplitude, phase, and
uncertainty data for monolayer WS2, WSe2, and MoSe2 under CC BY 4.0:

- Record and download: https://doi.org/10.18453/rosdok_id00004699
- Data archive: `Voelzer_2025_Daten.zip` (902,610,928 bytes on 2026-08-31)
- Local documentation: `RosDok_Monolayer_TMDC_documentation.pdf`

The 903 MB data archive is intentionally not duplicated here. None of its three materials
has a matching completed kernel in this project yet. Fetch it from the DOI when one becomes
the calculation target; the small documentation PDF records the full file layout now.
